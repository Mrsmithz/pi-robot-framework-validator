# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the issue without further decisions. |
| `ready-for-human` | `ready-for-human` | A human needs to implement the issue. |
| `wontfix` | `wontfix` | The issue will not be acted on. |

Use the GitHub label for the role named by the skill. Wayfinder issues use their own labels.
